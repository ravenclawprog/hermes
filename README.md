# HERMES

**Hermes** — микросервисная платформа для совместной работы с удалёнными документами
через консольный клиент. Проект разрабатывается с упором на распределённую архитектуру,
асинхронную доставку событий и горизонтальное масштабирование.

Сейчас прорабатывается архитектура. Реализован начальный CLI на Go: каркас команд
и запуск системного редактора; серверные операции пока заменены заглушками.

## 🚀 Основной функционал

Целевые возможности проекта:

- **Управление документами:** создание, чтение, изменение и удаление документов в рабочих пространствах.
- **Консольный интерфейс:** отдельные CLI-команды и интерактивный терминальный интерфейс (TUI).
- **Интерактивное редактирование:** работа с текстом через системный редактор, например Vim или Nano.
- **Уведомления в реальном времени:** доставка сообщений об изменениях через WebSocket.
- **Оптимистическая блокировка:** проверка версии документа для защиты от конфликтующих изменений.

## 🛠 Технологический стек и архитектура

- **Go** — клиент и серверные приложения.
- **PostgreSQL** — хранение предметных данных.
- **Apache Kafka** — передача предметных событий между сервисами.
- **Redis** — общее хранилище активных сессий; Pub/Sub для обновления настроек рассматривается отдельно.
- **Docker / Kubernetes** — планируемое окружение развёртывания.

Общая схема компонентов: [arch/arch.puml](arch/arch.puml).

## 📦 Зависимости проекта

Для текущего CLI:

- **Go** — версия указана в [go.mod](apps/hermes-cli/go.mod).
- **Vim / Nano** или другой редактор, заданный через `EDITOR`.
- **Task** — опционально, для команд из [Taskfile.yml](apps/hermes-cli/Taskfile.yml).

Для будущего серверного окружения:

- **PostgreSQL** — предметные данные.
- **Apache Kafka** — шина событий.
- **Redis** — активные сессии.
- **Docker & Docker Compose** — планируемый локальный запуск инфраструктуры.
